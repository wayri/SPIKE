# CalculiX Thermal Suite

Original SPIKE Apache-2.0 process adapter for a separately installed CalculiX
CrunchiX executable. See [workflow, contracts, licensing and numerical
evidence](../../docs/CALCULIX_THERMAL.md). No external solver is bundled.

`calculix-thermal` and `calculix-thermal-prepare` prepare a retained assembly
thermal field request and problem. `calculix-thermal-run` executes the fixed
trusted deck compiler and external runtime. Results remain experimental.
