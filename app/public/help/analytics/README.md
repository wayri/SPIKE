# Numerical analytics help assets

These PNG files are generated by `scripts/generate_analysis_gallery.py` from
executed first-party numerical examples. They are analytics plots, not
application screenshots. Provenance, exact metrics, source hashes, limitations,
and compact plotted series are stored under `examples/analysis_gallery/`.

Use root-relative help paths such as:

```text
/help/analytics/pi-dielectric-admittance.png
/help/analytics/si-rlgc-line-fields.png
/help/analytics/em-huygens-far-field.png
/help/analytics/thermal-two-solid-conduction.png
/help/analytics/hybrid-electrothermal-convergence.png
/help/analytics/cfd-native-cavity.png
/help/analytics/cht-laminar-channel.png
/help/analytics/multiboard-coupled-networks.png
```
