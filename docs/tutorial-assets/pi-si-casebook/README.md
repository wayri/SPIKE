# PI/SI casebook capture provenance

All nine PNGs here are original screenshots of SPIKE's offline artifact views
generated by `scripts/render_pi_si_tutorial_pages.py` and captured locally
with headless Google Chrome on Windows, 2026-09-28. They are MIT-licensed
SPIKE-owned documentation assets; no third-party screenshot, board image,
model, icon, or font was copied into them. Segoe UI/Consolas are displayed
using local system fonts and are not distributed.

The source views read actual generated JSON under `build/tutorial-pi-si/`.
The Marble AC gate view reads the external board only to bind its SHA-256 to
the audit. The Marble R293 SI view reads a run that imported the pinned board
and checked four pad/net identities; it includes derived net names, counts and
the board hash, not board artwork. The board remains with Berkeley Lab under
CERN OHL v1.2; its provenance and notices are recorded in the root
`THIRD_PARTY_NOTICES.md`. The casebook and companion R293 tutorial give the
commands, model ownership, expected results, and limitations.

To refresh a capture after rerunning the casebook commands:

```powershell
$base = (Resolve-Path .).Path
$name = 'dc'  # ac, transient, si, si-time, touchstone, 10g, marble-gate, marble-r293-si
$browser = 'C:\Program Files\Google\Chrome\Application\chrome.exe'
$input = (Resolve-Path -LiteralPath "build/tutorial-pi-si/pages/$name.html").Path
$output = Join-Path $base "docs/tutorial-assets/pi-si-casebook/$name.png"
$profile = Join-Path $base "build/tutorial-pi-si/chrome-$name"
& $browser --headless --disable-gpu --no-sandbox --no-first-run --user-data-dir=$profile --window-size=1440,980 --screenshot=$output ([System.Uri]$input).AbsoluteUri
```

The Marble gate used a 1440x1100 window; R293 used 1440x1120.
These are executed-artifact screenshots, not desktop-application screenshots
or evidence that a board or Ethernet PHY is qualified.
