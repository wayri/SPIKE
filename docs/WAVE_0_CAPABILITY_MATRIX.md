the numerical method is validated for engineering signoff. Approximate,
experimental, reference-only, unavailable, and blocked states remain explicit.

## Wave 0 stability exit

The workspace-recall slice is complete at repository-contract level when the
frontend workspace tests, package tests, TypeScript check, Python package and
worker round trips, schema catalog, architecture guard, and packaged restart
acceptance pass. The last item remains a release-environment test.

The source-versus-packaged runtime qualification is an additional hard Wave 0
gate. The 2026-08-20 report passes all eight required checks with no collection
errors and identical source/package snapshot digests. See
`docs/RELEASE_RUNTIME_QUALIFICATION.md`. This closes runtime parity only. Wave 0
remains open for packaged restart, mixed-monitor, signing/SBOM, clean-machine,
and cross-platform acceptance; the validated PI gate also remains open for the
numerical evidence listed above.

## 2026-08-21 Wave 0 audit slice

The following narrow defects are closed at repository-test level without
promoting any solver's numerical-validity state:

- KiCad `uuid`/`tstamp` identities are retained for tracks, arc-derived
  segments, vias, footprints, pads, and their DesignIR v2 source mapping.
- `HybridMesh.to_preview` uses the same deterministic stratified admission
  policy as the standalone mesher. A mixed track/via/zone/pad regression proves
  kind coverage, input-order invariance, and deterministic truncation.
- DC result mesh, scalar-field, and visual-edge admission now use that shared
  policy. A stitched F.Cu/B.Cu regression proves both copper layers and the via
  span survive a 1,000-cell visual budget and that every scalar sample refers
  to an admitted mesh element.
- Transient result admission uses the same bounded, deterministic stratified
  policy for node fields, routed branches, vias, and preview records. It does
  not alter the physical solve graph; focused regressions prove repeatability
  and representation of late-built branch classes under constrained budgets.
- `run_field_circuit_cosimulation` and `run_spice_workspace_native_mna` are
  classified as heavy Rust-host operations and therefore use host single-flight
  and cancellation state.
- Engineering report board, graph, and Plotly render stages are isolated. A
  minimal offline runtime test proves board and graph output survive a missing
  Plotly runtime and that unavailable canvas contexts produce a named visible
  diagnostic instead of an empty surface.
- Reviewed ordered PI series paths survive the frontend-to-worker boundary with
  all net segments, explicit source/load pad anchors, and every intervening
  transition. Cross-net DC accepts only a finite non-negative resistance from
  the reviewed transition or explicit imported component metadata, records the
  resistance provenance, and stamps the component between its reviewed pads.
  The canonical `spike/pi-path-interface-elements/v1` preview/result contract
  carries exact endpoint coordinates, layers, nets, component identity,
  equivalent resistance, solved current/drop/loss, and provenance. The desktop
  renders the bridge with net/layer filtering and preserves it in AC/transient
  result bundles without fabricating a spatial scalar field. The contract marks
  the equivalent as non-volumetric and explicitly denies current-density
  support.
  Reviewed AC and transient paths preflight and extract each segment at its
  exact endpoint pads, require one unambiguous RLCG network per segment, and
  compose those networks with reviewed linear R/L/C bridges in native MNA.
  Segment networks and endpoint provenance remain in the result; no
  circuit-wide spatial field is invented. Missing, duplicate, mismatched,
  unreviewed, ideal-zero, and nonlinear transitions fail closed. Physical
  package/contact-volume meshing and automatic nonlinear ngspice composition
  remain open.

Verification evidence includes the complete 412-test Python suite with one
documented skip, the 10-test exact series-path backend suite, frontend
three-net/two-transition handoff, segment-orchestration and component-bridge
normalization/render-policy regressions, TypeScript checking, focused mesh and
result-geometry/layer regressions, an offline report-runtime test, a production
TypeScript/Vite build, and 4 Rust host tests. These tests
do not close the reported result-overlay streaks, real 32-layer desktop
acceptance, packaged restart, signing/SBOM, or validated PI gates.
