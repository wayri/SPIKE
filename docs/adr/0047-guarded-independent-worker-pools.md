# ADR 0047: guarded independent simulation worker pools

Status: implemented initial bounded boundary; broader scaling pending.

Python owns strict inline scheduling and mutually authenticated TLS. A dedicated
child dispatcher imports fixed numerical handlers without the broad service or
extension discovery. Rust supervises desktop processes; TypeScript presents
local controls. Administrator-controlled enrollment/private keys stay outside
portable projects. Optional UDP discovery cannot grant trust.

Peers require chain/hostname validation and explicit SHA256 node pinning;
clients require approved certificate fingerprints. One batch/node, capped
connections before handshake, absolute deadlines, bounded JSON and streamed
child output guard admission. Timeouts/cancel kill owned children. CPU budgets
are cooperative; portable hard memory containment is unavailable. This boundary
supports trusted operators, not hostile multi-tenant workloads.

Ordered results preserve hashes, node identity and model quality. Ambiguous
delivery is never retried automatically. Single-solve MPI and extra GPU backends
need separate numerical adapters/acceptance. No new dependency is introduced.

See [setup, limits and validation](../PARALLEL_WORKER_MANAGER.md).


## Portable project persistence

The additive `spike/parallel-workspace/v1` field in v3 `analyses` retains drafts
and immutable request/result records; desktop projections use the corresponding
`analysis.parallel_execution` field. App owns state outside the pool panel so
closing it does not erase history. Existing checksum-bound state artifacts carry
complete result envelopes. Offline admission verifies request and response
bindings. No portable record confers remote trust, resumes a process or changes
solver qualification. Enrollment remains in administrator-managed local files.
See [contract and limits](../PARALLEL_WORKSPACE_CONTRACT.md).
