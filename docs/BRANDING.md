# SPIKE Brand Assets

The current SPIKE program icon and favicon are original geometric project assets
drawn specifically for this project and contain no copied logos, words, or
third-party marks:

- `app/public/spike-mark.svg`
- `app/public/spike-icon.png`
- `app/public/favicon.png`
- `app/src-tauri/icons/icon.png`

The simplified mark uses an SPI monogram: S as a signal path, P as a broad
teal-to-amber power trace, and I as one tapered integrity spike. The source SVG
is the canonical asset; PNG and ICO files are generated from it. It is not
intended to imitate KiCad, Altium, Keysight, Cadence, Siemens, Ansys, or another
product identity.

This is an engineering record, not a legal trademark clearance. Before public commercial release:

1. Search relevant trademark databases in target markets.
2. Check software and hardware icon databases for confusingly similar marks.
3. Register SPIKE's word mark and logo only after clearance.
4. Keep source prompts, generation metadata, and asset hashes with the release record.
5. Do not add third-party logos to SPIKE's UI without permission.
