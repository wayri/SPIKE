# SPIKE 0.4.2 — experimental prerelease

**Numerical human review is incomplete.** On 26 October 2026 the project owner
explicitly authorized publication with that status disclosed. This exception
allows an experimental prerelease; it is not reviewer approval, engineering
qualification, or a change to any solver execution gate.

This release includes unified saved-frame playback for thermal, PI and CFD
results; combined fluid and solid-temperature views with exact time matching;
fixed/manual color ranges and sample inspection; and persistent labeled controls
for selected/analyzed-net highlighting, single-board analyzed-net isolation and
transparent geometry inspection. Solver-colored nets are filled and can be
inspected through translucent CAD context.

The accumulated desktop work also includes multiboard assembly workflows,
guarded solver integrations, IBIS driver/input-receiver workflows and 38 work
examples. The solver-folder [mathematics and references](../../python/spike_core/solvers/MATHEMATICS_AND_REFERENCES.md)
documents governing methods, assumptions, units, sources and evidence limits.

## Known limitations and verification

- The retained full Python run has **5,728 tests, 2 failures, 5 errors and 87
  skips**. Some focused reruns passed; no passing full suite for the final source
  is claimed. SI08 native acceptance evidence is stale.
- Focused field/viewport, TypeScript, architecture and release metadata checks
  passed. These do not replace physical validation or final installed-app tests.
- Final native UI and package lifecycle qualification remain incomplete.
  Fresh Linux and macOS 0.4.2 qualification is unavailable.
- The demonstrated native CHT case uses a board and declared component cuboids,
  not arbitrary detailed STEP parts. Its 0.020-second startup result is not
  thermal equilibrium. Component heating is prescribed; that example does not
  solve copper current losses. Detailed polygon-prism CAD CHT and broader
  mesh/time convergence remain unresolved.
- IBIS refinement and independent numerical accuracy/coverage review remain
  incomplete. Cosmetic moving streamline markers do not represent transient
  particle trajectories.

## Downloads

This publication is **source-only**. No 0.4.2 Windows, Linux or macOS installer
is attached. The retained local Windows preview predates the debugger repair;
its component inventory differs from its pending approval record. It is not
presented as a final-source build. Rebuilding and completing dependency and
package verification remain separate follow-up work. This release does not
