# SPIKE 0.4.0-alpha.1 — experimental multiphysics preview

**Numerical and firmware human review is pending.** This prerelease is not a
stable, qualified, safety-assured or production engineering release. Development
is largely LLM-driven; the project’s human-review requirement has not been
fulfilled for the integrated numerical changes. The owner explicitly requested
publication with this disclaimer: “not yet, make the release with the disclaimer”.
This is an exception for experimental publication only. It does not turn an
unreviewed method, model, package or test into reviewed/validated evidence.

## Included integration

- [Part operating limits](../PART_LIMITS.md): occurrence/part-specific voltage,
  current, temperature, power, mechanical stress and frequency checks; declared
  allowance stress/headroom percentages; per-part summaries; JSON/CSV pass,
  fail and incomplete reports with source provenance and coverage gaps.
- [Python workspace](../PYTHON_WORKSPACE.md): searchable templates with category
  and requirement matches, current SPIKES Studio runtime/handoff/feedback
  templates, and a worker-based engineering review/report template.
- SPIKES Owned Native Circuit Engine discovery and Solver Manager integration:
  named blocks/dependencies, native runtime content identity and additive ABI
  feature evidence. Symbol discovery alone does not enable unsupported worker
  operations or qualify a numerical model.
- [Main field viewport](../FIELD_VISUALIZATION.md): cells, points, velocity arrows
  and connected flow curves share the board scene/camera; compact contextual
  field controls and saved-frame playback replace the standalone field window.
- Integrated development across the solver suite, assemblies, import, materials,
  SPICE Studio and the clean interface, with capability-specific experimental,
  approximate and unsupported states retained. See [solver status](../SOLVER_STATUS.md).

## Scope and safeguards

Part-limit observations are explicit captured inputs. SPIKE does not infer
manufacturer ratings, automatically qualify all pins/corners, or turn arbitrary
solver fields into accepted part measurements. Temperature percentages use a
reference such as ambient, not a ratio of absolute Celsius values. Missing or
unreviewed evidence never becomes a pass. Limits checks are not reliability,
lifetime, fatigue or combined-stress qualification.

CFD/CHT, EM, SI, thermal, circuit and hybrid routes retain their individual
geometry, material, boundary-condition, solver and validation limits. Main-view
visualization does not establish solved-field accuracy. Renderer-generated flow
curves are approximate frozen-field presentation, not transient particle paths.
General arbitrary-assembly multiphysics, universal GPU acceleration, automatic
MCAD authoring, qualified firmware co-simulation and Blender rendering are not
claimed by this release.

Technical checks, source identity, publication identity, dependency/licensing,
artifact hashes and supported-platform packaging acceptance remain required.
The review exception does not waive these gates. Platform availability must be
read from the actual attached assets; an older installer is not this candidate.

Use independent references and knowledgeable engineering review before relying
on results. Report reproducible issues with anonymized diagnostics. See
[development disclosure](../LLM_DEVELOPMENT.md), [platform instructions](../PLATFORM_PACKAGES.md)
and [license](../../LICENSE). SPIKE is provided AS IS, without warranty or guarantee.
