# SPIKE 0.3.10 - Windows stability delta

## Desktop shutdown

- Closing the main workspace ends the whole native application, including its
  detached report, result, probe and assembly windows.
- Unsaved main-project Save, Discard and Cancel decisions are preserved. Failed
  or canceled saves keep the workspace open.
- An assembly draft that blocks closing now has a visible Review draft dialog
  that restores its tool window instead of only changing status text.
- Worker shutdown runs outside the UI event loop, cancels lightweight and heavy
  requests, rejects new work and uses bounded resident-process cleanup.
- An unresponsive renderer now has native close recovery with an explicit
  unsaved-work warning. Repeated requests and stale dialog responses cannot
  bypass a recovered workspace save guard.
- Windows installer verification requires the installed process to exit after
  a real main-window close. A forced cleanup does not pass that gate.

## Controls, navigation and search

- Application menus support keyboard opening, arrow navigation, Home/End,
  Escape dismissal and focus restoration.
- Universal search excludes unavailable actions, preserves editor shortcut
  ownership and IME composition, and keeps focus inside its dialog.
- Closed search skips board/net ranking; empty search stops after its first
  fourteen available entries. This avoids scanning large inventories on every
  unrelated workspace update.
- Project, benchmark, SPICE, stackup and thermal dialogs gain keyboard focus
  containment and recovery. Hidden/disabled controls are skipped.
- Shared button styling is enforced for interactive test fixture entrypoints.

## Repeatable stability gate

Every declared frontend test suite runs through `npm run test:ui-stability` with
bounded timeouts, checkpointed results and a failing exit code on regressions.
Source CI uses the same gate. Test harnesses have been repaired to reflect
current module boundaries, without dropping their behavioral assertions.

Read [stability coverage](../UI_STABILITY.md) and
[close recovery](../DESKTOP_SHUTDOWN.md). Automated contract checks and selected
native interactions do not certify every menu/runtime state, external engine,
screen reader, or numerical model.

## Scope and downloads

This unsigned Windows x64 community preview is based on published 0.3.9 plus
scoped desktop lifecycle, controls, search and verification changes. Numerical
solver implementations are unchanged. Optional external engines are installed
separately. Linux and Apple Silicon downloads remain at 0.3.5; Intel macOS is held.

Development is largely LLM-driven under human review. This remains an early
preview with possible defects, instabilities and incomplete behavior. Please
report reproducible issues and feedback. Numerical results retain their stated
model assumptions and validation limits.
