# SPIKE 0.3.9 Windows community preview candidate

Candidate status: built locally, not yet published. EXE/MSI packaging, extracted
payload hashes, CLI runtime checks and the full Python suite passed. Native
offline, upgrade and export checks and knowledgeable human numerical review
are required before publication.

SPIKE remains an early community preview. Much of the implementation effort is
LLM-driven under human direction and review. Instabilities and defects may
remain. Community testing, reproducible issue reports and feedback are welcome.

## Included work

- Arbitrary assembly sections, up to six planes and interior box cuts, with
  matching rendered geometry and picking half-spaces.
- Exploded-board transforms also move attached harness endpoints.
- Conservative cached offscreen occurrence culling with shadow refresh safety.
- Timestamp-based saved-result playback and bounded GIF/WebM export.
- Closed-loop behavioral PWM buck electrothermal reference from PI and Thermal,
  request-bound saved results, native progress, cancellation and cycle plots.
- Branched supplied-RLGC harness SI kernels and a bounded round-wire/ideal-plane
  extractor available through the worker and headless MCP tools.
- Repaired Raspberry Pi example package reopening, with retained PI, SI and
  thermal results reproduced through actual desktop-worker reruns.

## Demonstrations and limits

See [acceptance audit](../CAPABILITY_ACCEPTANCE_20261009.md) for exact evidence
and incomplete requirements, and the [demonstration guide](DEMO_0.3.9.md) for
retained example/result locations and steps. The PWM example couples winding resistance to a
lumped thermal state; ideal gate control and finite-conductance switches do not
qualify vendor switching losses, semiconductor cooling or EMI. Existing
multiboard examples use explicit reduced electrical networks. The thermal
comparison uses declared synthetic boundary conditions.

This preview does not establish the requested combined arbitrary converter,
airflow, SI and radiated-EMI simulation. Saved playback pause does not pause a
solver job. Numerical outputs retain their experimental/approximate status.
