# SPIKE 0.3.9 - Windows community preview

## Assembly viewport and controls

- Orbit rendering follows display refresh during gestures; quality restoration waits for the motion to settle.
- Harness conductors use shaded cable geometry, depth occlusion and individual-wire picking. Cable radius and curved paths are presentation assumptions, not measured insulation or solver geometry.
- Compact icon controls retain mini labels, accessible names and tooltips. Assembly help explains navigation and command-line structure edits; the verification window uses a collapsible placement/display inspector and side rail.
- Rendering fixes cover occurrence culling, clipped picking, laminate alignment and occurrence-bound thermal overlays. No numerical solver implementation changes are included relative to 0.3.8.

## Downloads and scope

This release provides unsigned Windows x64 NSIS installer, with SHA-256 checksums. Optional external engines are installed separately. Linux and Apple Silicon downloads remain at 0.3.5; macOS Intel remains held.

Development is largely LLM-driven under human review. SPIKE remains a very early community preview and may contain instabilities, defects and incomplete behavior. Please test it and report reproducible issues. Results retain their stated model assumptions and validation limits; UI availability does not qualify a complete coupled multiphysics workflow.

The newer numerical development candidate remains separate pending its required human review. These installers are built from published 0.3.8 plus the scoped rendering/control changes.
