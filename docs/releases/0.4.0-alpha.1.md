# SPIKE 0.4.0-alpha.1 candidate

Status: integrated alpha candidate; public publication is blocked pending required
knowledgeable human numerical review and release acceptance. This is not a beta,
stable, production-qualified, or long-term-support release.

## Integrated development

- Refined Clean and Classic workspaces, editor tabs, contextual camera/selection
  tools, light/graphite/AMOLED appearance options, retained panel drafts and compact
  show/hide recovery controls. Large ribbons and quick tools remain opt-in in Clean.
- Desktop source drop review for KiCad boards, ODB++ jobs/archives and the existing
  STEP/STP/GLB/glTF attachment workflow. Up to 32 sources are reviewed individually.
  ODB++ compressed matrix-root discovery now matches bounded compressed-member
  handling, with original source identity and unsupported-copper diagnostics.
- Solver-suite organization and ongoing Studio, assembly, material and MCAD
  integration. Availability and solver results remain capability-gated.
- Experimental supplied RLGC networks, fields, piecewise cascades and ideal star
  junctions; geometry extraction, broadband causality and production qualification
  are not inferred from these supplied-parameter models.
- Opt-in native linear RLC Radau IIA3 integration and the latest thermal, airflow,
  coupling and geometry work, with their documented formulation and runtime limits.

See [solver status](../SOLVER_STATUS.md), [method evidence](../NUMERICAL_METHOD_EVIDENCE.md)
and [ODB++ usage](../ODB_AND_HARNESS_EXTENSIONS.md) for scope and reproduction.

## Acceptance still required

- Knowledgeable human numerical review. Agent review supports this gate and does
  not replace it. Independent physical validation remains incomplete.
- Portable final-revision regression evidence, required dependency approvals
  and four matching platform artifacts. Fresh local Windows native/frozen checks
  are recorded in [candidate readiness](../validation/ALPHA_0_4_READINESS_20261019.md).
- Supported-platform install, offline, upgrade and uninstall acceptance. Native OS
  file-drop acceptance has not yet been manually exercised for this candidate.
- EBrake AC copper-support/passivity and DC current-density convergence remain
  unresolved. EBrake and Marble are not qualified for full-board SI/PI.
- CUDA hardware qualification and an admitted Xyce runtime remain optional gaps.
  External engines retain their own installation and license boundaries.

No 0.3.x installer is being relabeled as 0.4. The Windows installer remains unsigned;
Linux/macOS distribution status must follow actual artifact acceptance.
