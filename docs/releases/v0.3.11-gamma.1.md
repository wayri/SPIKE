**Gamma warning: numerical and engineering reviews are pending.** The owner explicitly authorized this prerelease with that limitation. Back up projects before installing and avoid replacing a working production toolchain with this preview.

## Development included

- MCP/SpiDeR modern and legacy protocol support, discovery, typed tools, installed schema resources, bounded queries, normalization and revision comparisons.
- Board-linked Studio circuit extraction and explicit electrothermal/geometry feedback interfaces. Full standalone Studio launch remains a source/separate-runtime workflow; it is not a new bundled native Studio installer.
- Desktop, multiboard, selection, studies, probing, shortcut and control improvements.
- PI/SI AC losses and roughness workflows; assembly EM, machine/actuator, CFD/CHT and transient development with each operation's own admission requirements and validity limits.
- Published 0.3.10 shutdown and unsaved-work protections retained while integrating newer worker/update routes.

UI availability does not imply solver qualification. Optional external engines, solver binaries and private or redistribution-uncleared model collections are not bundled. Source examples with established licenses retain those licenses and notices. No KiVi source has been imported under the instance-only grant; schematic support uses the independently implemented KiCad CLI adapter.

## Package and evidence

This is an unsigned Windows x64 Gamma preview. Linux and macOS binaries are not refreshed in this release.
