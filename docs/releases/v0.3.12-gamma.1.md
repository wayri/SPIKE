# SPIKE 0.3.12-gamma.1

**Gamma community prerelease. Numerical and release-qualification reviews remain
pending. This is not a production-qualified or stable release.**

PCB-focused multiphysics, from board to complete assembly. This release integrates
the current first-party development work while preserving each solver's actual
implemented, approximate, experimental, external or unsupported status.

## Included development

- Clean and Classic interface layouts, context quick tools, searchable commands,
  sentence-based setup workflows, editable/resizable and detachable panels.
- Named Solver Manager entries with domain/provider/status filters and explicit
  setup routes, including bounded electrical, thermal, fluid, magnetic,
  structural and circuit workflows.
- Versioned material evidence, part/board/layer snapshots and read-only FreeCAD
  material exchange; reviewed placement feedback retains its existing limits.
- Bounded finite-radius rectangular sheet and flex folding previews. This does
  not fold an imported PCB's copper/components or create a folded solver mesh.
- Current solver-suite and SPIKES Studio integration development, with capability
  and validation evidence retained in the source documentation.
- Windows embedded-frontend packaging and worker/native producer integration.
- Community links and PCB-to-complete-assembly product scope documentation.

## Important limits

General arbitrary-assembly multiphysics, universal large-model GPU acceleration,
automatic material-law integration, arbitrary sheet-metal unfolding and fully
qualified folded PCB analysis are not established by this release. Optional
external engines must be installed and admitted separately. The CAD air-complement
mesher for assembly OpenFOAM CHT remains a pinned Windows development runtime;
it is not a portable packaged assembly-CFD capability. The bundled native cavity
reference remains a separate, bounded experimental solver.

Pending knowledgeable human numerical review, independent physical validation,
dependency redistribution review and clean-machine acceptance are not replaced
by automated tests or a Gamma label. Check the attached verification record for
the exact checks performed and skipped for these artifacts.

This is an unsigned Windows x64 preview. Other platforms are not refreshed by a
Windows-only build. Do not infer new Linux/macOS validation from older downloads.
No private model collections, quarantined upstream example corpus, generated
working output or redistribution-uncleared fixtures are included in the reviewed
release source selection.
