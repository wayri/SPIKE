# SPIKE 0.4.3 - UI and power-tree hotfix

Source-only experimental prerelease, based on published 0.4.2 commit
`390e6d56466955cc7a5ad886ff528a9269a1adb6`.

- Center the workspace search and move secondary utilities to the right.
- Correct the collapsed Board Nets chevron and keep the net panel clear of the
  axis navigator. Replace separate rotation buttons with axis rotation rings.
- Open saved thermal studies in thermal setup instead of PI setup.
- Improve the power-tree overview with directional branches, collapse, fit,
  zoom and selection/evidence details. Improve pin-role inference, regulator
  and PMIC output handling, and ground rejection; inferred paths need review.
- Add the **Geometry -> basic PI** command. This hands normalized PCB copper
  to the already released `spike.routed_dc` resistive-network solver and returns
  its existing geometry-linked fields. It does not infer electrical properties
  from arbitrary STEP solids. See [the workflow](../GEOMETRY_PI_HANDOFF.md).

No solver or native numerical kernel changes are included. New CFD, turbulence,
force/torque, AC and other development capabilities are excluded from this patch.
Existing power-budget calculation mathematics is unchanged.

## Verification and limits

Focused UI, power-tree and geometry-adapter tests, parser regression, TypeScript,
button-standard and architecture checks, and the production frontend build pass.
A real worker handoff on a declared copper track returned the existing approximate
DC result with 12 geometry faces and voltage/current/current-density/loss fields.
Browser checks exercised the centered header, geometry search command and
power-tree fit/collapse behavior. These are not installed-app acceptance.

Native host tests: 80 pass, 1 fails because this source checkout has no packaged
worker executable, and 1 live-OS test is ignored. The default Cargo build also
requires that absent worker resource; the host test run used a test-only empty
bundle-resource override. No installer qualification is claimed.

The full Python run completed with 5,694 tests: 35 failures, 115 errors and 210
skips. It does not pass. Details and the exact scope audit are recorded in the
[validation record](../validation/RELEASE_0_4_3_HOTFIX.md).

**Numerical human review remains incomplete.** The owner's prior authorization
allows an experimental publication with this disclosed status. Existing numerical
provenance and validation gaps and execution gates remain in effect. This release
is not engineering qualification.

Assets are a committed-source ZIP and SHA-256 checksum only. There is no new
installer, and publication does not update an existing installation. The wider
physics and detailed imported-part CFD work remains outside this release.
