3. Preserve the SPIKE-owned `examples/upstream-emerge/bridge.py` and `examples/upstream-emerge/studies/` files; only the copied upstream `source/` cache and packaging helper are excluded.
4. Keep the ESP32 source license/provenance files and the analysis/UI manifests in the public source snapshot.
5. A knowledgeable human license review remains open. This audit does not set or forge an approval state.
