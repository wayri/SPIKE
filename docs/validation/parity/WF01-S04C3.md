# Native STEP component placement reference

WF01-S04C3 is a bounded geometry reference, not automatic source-model placement
or physics/material qualification. All inputs are originally authored SPIKE
fixtures; no external model, source implementation or test data was copied.
Generated geometry/data and original validation scripts are Apache-2.0.
Separately installed KiCad 10.0.6 and FreeCAD 1.1.3 are not redistributed.

## Observed and independently checked

Twelve component instances cover front/back sides, 90/37 degree footprint angles
and three offset/rotation/positive-scale sets. The original 2x3x4 mm STEP cube
has eight distinct corners and volume 24 mm3. Each native solid is valid; its
eight corners, transformed bounds and volume match independently authored
matrix arithmetic. The nonuniform scale (2,1,0.5) has determinant one: corner
checks distinguish its geometry, while volume alone cannot.

The native checker observed maximum corner error 8.413e-12 mm and maximum volume
error 7.106e-15 mm3. The independent roadmap gate recomputes geometry to 1e-6 mm
and 1e-6 mm3; it does not trust stored expected values or pass flags. Eight
native exports returned zero. Actual solids, input boards, commands, reader
output and script/source hashes are retained in
`benchmarks/parity-import/native-step-reference/` and the
[native reference](WF01-S04C3-native-step.json). The
[stage receipt](WF01-S04C3.json) binds the independent validators.

## Coordinate and clearance controls

For this stack, native STEP core occupies Z=0..1.53 mm. An explicit copper
export measures front copper Z=1.53..1.565 and back copper Z=-0.035..0 mm.
The full physical stack is 1.6 mm, independently of the core-only exported body.
SPIKE board-local coordinates are `(x,-y,1.565-z)` mm: depth begins at the full
stack top, with dielectric depth 0.035..1.565 and bottom depth 1.6.

Native component mounting elevations are front 1.615 and back -0.085 mm.
The resulting 0.05 mm clearance is retained in the reference; it is not removed
to force contact. A separate `--no-extra-pad-thickness` export leaves those
component placements unchanged. Its internal cause and physical suitability
are not established. Compared with VRML, STEP also uses a different Z datum;
WRL's 2.54 mm/unit conversion does not apply to the original mm-valued STEP.

## Reproduction

Use installed native runtimes. Keep source and generated results separate:

```powershell
.venv/Scripts/python.exe benchmarks/parity-import/native-step-reference/run_reference.py --repo-root "$PWD" --output-root "$PWD/build/native-step-replay"
.venv/Scripts/python.exe -m unittest tests.python.test_parity_component_placement tests.python.test_parity_backlog -v
.venv/Scripts/python.exe scripts/check_parity_backlog.py
```

The launcher accepts `--cli`, `--kicad-python` and `--freecad-python` paths.
It bounds each native command, retains failures and returns an error on an
unsuccessful command. When scripts and outputs are separate, retain the
launcher/reader/checker source hashes externally as well; the checked-in stage
bundle keeps them together. A rerun does not replace the accepted receipt.
KiCad may write project-local settings; use disposable reproduction outputs.
Registry warnings occurred in this host's sandbox despite successful exports;
the earlier VRML timeout cause remains unknown.

## Remaining scope

This covers one stack, one cuboid, two footprint angles, three positive source
vector sets and one native version. Negative/degenerate scales, arbitrary
solids, other stackups/versions, automatic source projection and actual
conditioned material evidence remain open. Explicit STEP handoffs still require
reviewed placement; source transforms remain unapplied. Parent WF01-S04C remains
In progress. DRC, connectivity, release readiness and thermal predictions are
not established by this geometry reference.
