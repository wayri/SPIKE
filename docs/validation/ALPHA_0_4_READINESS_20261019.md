# 0.4.0-alpha.1 candidate readiness, 2026-10-19

This is an integration and verification record, not release approval.
Publication remains blocked by knowledgeable human numerical review and release
acceptance. The original development checkout and index were preserved; the
candidate was captured on published base `dc3cdc83` as commit `591e97f`.
The capture cutoff was 2026-10-18 19:38 UTC. A later drift check found changes in
36 captured paths in the concurrently used development checkout, including mesh,
native C API and Studio code. Those post-cutoff changes were preserved there and
were not silently added to this verified snapshot. Reconciliation with that later
development is a separate integration gate before claiming that a future public
release contains all work then present in the development checkout.
Later candidate-only changes refresh help/catalog inventories, repair test setup,
restore exact bound evidence, update portable documentation and refresh import
receipts through real execution. Numerical implementation files are unchanged
by this release-preparation follow-through.

## Portable evidence refresh

The release snapshot initially omitted 34 receipt-bound first-party test logs.
Their exact recorded SHA-256 bytes were recovered after content review; no test
result, source hash or qualification flag was hand-edited to force acceptance.
The numerical and placement evidence gates then passed their scoped reruns.

The final source audit also found platform-dependent newline hashes. Active source
files were pinned to canonical LF only after proving newline normalization exactly
matched their existing Git blobs. Bound data retains exact bytes. Old canonical
captures are preserved when existing downstream consumers require fresh captures
at their fixed paths. Current evidence is regenerated by actual import/test runners
and checked through the existing independent validators.

A real FreeCAD export refreshed three component solids after checkout-dependent
source provenance changed. Existing gates checked 24 mm³ per solid, analytical
bounds and STEP round trips. This is mechanical handoff evidence, with material
and physics qualification still false; it is not a multiphysics validation claim.

Final portable evidence checks passed: all 40 active stage validators, 83 tests
executed by nine actual receipt generators, and 55 final parity/backlog tests.
The audit verified 243 referenced implementation, test and schema files against
canonical Git bytes. Eight replaced historical captures are retained with
their original hashes in `parity/history/0.4-portability/`. After staging,
the parent reran all 55 parity/backlog tests successfully with both
`core.autocrlf=false` and `core.autocrlf=true` Git materialization. All 266
recursively referenced source/data inputs retained their indexed bytes.
These checkout-setting checks ran on Windows; they do not qualify Linux
or macOS execution. Architecture and all 534 staged public documentation
files passed; generated help remained current after materialization.

## Release gates still open

- Knowledgeable human review of the latest numerical changes, with reviewer,
  source revision, scope and approval record, as required by CONTRIBUTING.md.
- Required dependency/provenance and redistribution approvals, including local
  evidence inputs. The bounded agent review is not legal or human approval.
- Four current-source platform artifacts and their version/hash verification.
  Windows frozen-worker checks do not qualify Linux or either macOS architecture.
- Supported-platform installation, offline use, upgrade and uninstall acceptance.
  Native OS file-drop acceptance and the complete visual acceptance matrix have
  not been manually exercised for this candidate.
- Actual-board PI/SI and physical multiphysics qualification remain incomplete.
  EBrake AC copper-support/passivity and DC current-density convergence issues,
  Marble/full-board scope and optional CUDA/Xyce limits remain documented.
