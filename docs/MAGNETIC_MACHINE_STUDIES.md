# Geometry-based machine and actuator studies

SPIKE now includes an experimental planar P1 magnetic FEM workflow, separate
from the constant-parameter machine models. Open **EM > Machines > Geometry
field study**. Enter a study JSON request, run the desktop worker, and inspect
the actual mesh, B/H vectors, field magnitudes, Maxwell-stress contour and
mechanical histories. The browser preview cannot execute the desktop worker.
The request and result are retained in the existing project EM setup.

## Reproduce original demonstrations

From the repository root:

~~~powershell
.venv/Scripts/python.exe -m python.spike_core.cli --output "$env:TEMP/spike-em-machines/planar-pm-fem-result.json" magnetic-machine --request examples/em_machines/planar_pm_fem.json
.venv/Scripts/python.exe -m python.spike_core.cli --output "$env:TEMP/spike-em-machines/planar-solenoid-fem-result.json" magnetic-machine --request examples/em_machines/planar_solenoid_fem.json
~~~

The first example rotates a supplied-current PM machine using a field solve at
each accepted position. The second starts a stationary nonlinear solenoid from
zero magnetic potential, solves eddy-current diffusion and deposits actual
Joule losses into thermal elements. Its additional winding loss density is
an explicitly supplied ideal DC value J^2/sigma, not circuit-solved heating.
Example material values are synthetic demonstration inputs, not measured
material characterization or a commercial machine reference.

## Contracts and units

Worker method `run_magnetic_machine` accepts exactly `{request: study}`.
Study contract is `spike/magnetic-machine-study/v1`; result contract is
`spike/magnetic-machine-study-result/v1`. Models are `pm_rotor` and `solenoid`.
Both public schemas are registered in `schemas/manifest.json`; numerical
admission additionally checks connectivity, material monotonicity and convergence.
Geometry is generated by `machine_geometry.py`. Coordinates, mesh edge and
stack depth are metres; remanence is tesla; Jz is A/m^2. B-H pairs are [T,A/m].
Position is rotor radians or armature displacement metres. Force is N and
torque is N m about the coordinate origin. Positive solenoid displacement
increases the gap. Motion input mass/inertia, damping and load use respectively
kg, N s/m, N for translation and kg m^2, N m s/rad, N m for rotation.

The outer magnetic boundary has Az=0. A finite outer boundary is an
approximation; enlarge the outer domain independently of mesh refinement.
PM geometry defaults to a conforming polar mesh with material interfaces on
radial rings and mandatory magnet/slot rays. Circular surfaces are inscribed
polygons and the outer air boundary is circular. Each rotor position remeshes;
there is no sliding interface or transported moving-conductor state. Solenoid
geometry defaults to boundary-aligned Cartesian remeshing. Explicit legacy
`mesh_method: fixed_cartesian` retains approximate centroid attribution.

The magnet law uses a linear recoil permeability and supplied remanence. Steel
can use a positive permeability or monotone piecewise-linear B-H curve. No
B-H extrapolation is allowed. See [magnetic FEM](MAGNETIC_FEM.md) for the
variational formulation, Newton tangent, conditioning and analytical oracles.

Force/torque integrate vacuum Maxwell stress on a closed counterclockwise air
contour. Each complete segment must be covered by admitted air triangles. A contour
intersecting steel/magnet triangles or itself is rejected; refine or move it.
No missing field value is extrapolated. Integration uses the returned P1
element field, exact integration through crossed element intervals and physical
stack depth. Shared-edge contours use the contour-interior field trace; rejected
gaps and the retained roundoff-unresolved length prevent field extrapolation. Torque
includes the position cross force arm about (0,0). An independent infinite
current plus uniform external field verifies F=I L cross B and its moment arm.

## Motion and stationary electrothermal coupling

Optional `motion` runs bounded IMEX damped symplectic Euler mechanics with a
magnetostatic solve at every new position. It holds winding current density
fixed. Refine both the mesh and mechanical time step. This does not solve a
voltage-driven winding, commutation, generator load or motional v cross B.
Motion is limited to 100 steps and two million element steps. A position that
closes the gap, leaves the air box, or invalidates the stress contour fails.
The summary is explicitly initial-position data; the displayed final field and
histories identify their actual positions.

Optional `transient` selects **stationary** eddy/thermal coupling. It requires
time step, step count, initial temperature, explicit thermal material laws,
ambient temperature, exterior-edge convection coefficient and initial magnetic
field (`zero` or `steady`). Optional regional conductivity coefficients apply
sigma(T)=sigma_ref/[1+alpha*(T-T_ref)] to previous volume-weighted regional
temperature. Optional regional loss densities are nonnegative W/m^3.
All actual eddy element watts transfer to the thermal mesh. Returned frames
retain nodal temperatures, magnetic potential, B and element watts; step audits
retain magnetic and thermal energy balances. Initial frame has no computed
eddy-loss value. See [magnetic thermal coupling](MAGNETIC_THERMAL.md).

Motion and stationary transient modes cannot be combined: moving-conductor
eddy terms and conservative remesh state transfer are not implemented.
Thermal conduction is extruded planar; air is static conducting material.
Only the explicit outer edges exchange convection. There is no solved airflow,
end-face cooling, radiation, temperature-dependent magnetization or B-H law.

## Verification and remaining full-suite requirements

Original tests cover manufactured Poisson mesh convergence, nonlinear layered
B-H fields, tangent differences, PM affine fields, stationary eddy diffusion,
independent semi-discrete time refinement, zero net regional induced current,
Joule transfer, thermal storage/convection balances, conductivity feedback,
coupling-step refinement, geometry attribution, Lorentz force/torque, zero-force
motion, worker failures and CLI routing. Passing those tests establishes their
bounded numerical cases, not accuracy of an arbitrary machine design.

The requested full machine suite remains incomplete: conforming sliding
interfaces, actual retained STEP 3D magnetics, moving-conductor eddy loss,
field/circuit drive coupling, hysteresis/core loss, magnet demagnetization and
temperature-dependent magnetic material laws, moving-body thermal/CFD coupling,
and independent established-solver correlation must still be implemented and
qualified. Numerical human review is required before release. No release is
made by these changes.

Actual PM torque refinement at angle 0.123 rad, Jz=1e6 A/m^2, Br=1 T and
0.02 m depth yielded -0.048422627, -0.029006205 and -0.016534028 N m at
2, 1 and 0.5 mm meshes. The sign is stable and successive changes decrease,
but the finest change is still about 75% of the finest torque. It is **not
accuracy-converged**. The 0.5 mm full field exceeds the current transport cap.
The three-level geometry regression checks shrinking differences, without
asserting an invented exact torque. The result explicitly reports force/torque
accuracy as not qualified; kernel analytical tests cannot replace this gate.

Results are capped at 24 MiB for worker transport. Reduce stored snapshots or
coarsen the mesh when admission limits reject a study; do not discard validity
diagnostics to make it fit. Long solves use the existing supervised worker.
