# Drive–FEM–propeller closure audit

Read-only source audit, 23 October 2026. Scope: the existing planar magnetic kernels/machine wrapper and native SPIKES sampled-controller/session APIs. No new physics, solver/app edits or execution evidence is supplied by this audit. Findings are bound to the hashes below; concurrent solver work must be reviewed separately.

**Finding:** no existing callable in the inspected paths closes controller terminal voltages → FEM winding currents/flux → field-derived torque and back-EMF → shaft/propeller reaction → controller sensing. The pieces below are reusable, but separate successful runs do not establish that loop. A bounded genuine 2D/quasi-static coupling is possible in principle without claiming unsupported 3D moving-conductor physics, provided the missing electrical-port/energy contracts and numerical checks are implemented.

## Minimum mathematical contract for real coupling

These are independently reasoned requirements, not claims of existing implementation or a numerical-method approval.

1. **Normalize electrical winding ports.** Define signed winding functions χₖ(x,θ), units m⁻², including turns and conductor/parallel-path assignment, so `Jz=Σ χₖ iₖ` with phase currents in A. In a balanced planar winding, signed conductor contributions must cancel appropriately; test gauge invariance and positive/negative conductor/terminal orientation. For P1 fields and depth d, a candidate terminal linkage is `λₖ=d∫χₖ Az dA` in Wb-turn. The same source basis used to excite the field must extract linkage; arbitrary region averages or multiplying |B| by an unrelated area are insufficient.
2. **Close terminal voltage from the same flux.** Solve `v=R i+dλ(i,θ)/dt`, adding separately declared end-turn/leakage terms only when absent from the FEM port definition. The motion term `∂λ/∂θ · ω` is the field-derived back-EMF. Adding an unrelated supplied `Ke·ω` on top double-counts or breaks reciprocity. A single scalar J amplitude does not provide a three-phase inverter model.
3. **Use one conservative torque/linkage formulation.** For an established complete port coenergy W′(i,θ), require `λ=∂W′/∂i` and `τ=∂W′/∂θ`; hence `∂λₖ/∂θ=∂τ/∂iₖ`. Fixed-position incremental inductance must be symmetric and appropriately passive for the admitted stable constitutive law. An implementation must validate PM source/reference treatment before treating the kernel's reported constitutive coenergy as W′. Compare winding-port virtual work/energy torque against the existing Maxwell-stress torque with mesh/exterior/contour refinement; kernel Newton convergence alone does not close this check.
4. **Couple shaft and propeller reaction.** Advance `Jshaft·dω/dt=τFEM−τprop−bω`, `dθ/dt=ω`, with compatible sign/axis/rotation and actual shared inertia/load identities. Propeller shaft power must be `τprop·ω`; thrust and fluid momentum/work must come from an explicitly applicable aerodynamic model/result with its own assumptions and uncertainty. A prescribed thrust or independent fan-speed field is not electrical-to-propeller closure. A validated quasi-steady propeller map could support a bounded coupled demonstration; it must not be described as fully resolved transient CFD.
5. **Audit the common time step.** Terminal work must balance winding losses, change in admitted magnetic energy, shaft work and declared losses; shaft work must balance inertia, propeller work and damping. Account for integrator dissipation separately. Use converged implicit/partitioned iteration or a justified stable staggered scheme, a common controller sampling contract, failure/cancellation semantics and rollback of **all** electrical, field, mechanical, aerodynamic and controller states. Report unresolved coupling residuals rather than returning independent successful subruns as a completed coupled step.

## What would establish the requested claim

An explicit drive-state/provider contract must return the same revision-bound phase currents, phase flux linkages, terminal voltages, accepted rotor pose/speed, field torque, propeller reaction/thrust and energy ledgers for each accepted step. Port signs, turns, depth, units, mesh/material identities and coordinate transforms must be persisted, along with the source of the rotor/winding/propeller geometry. Required acceptance includes zero-current PM linkage, locked-rotor incremental inductance, current/angle reversal, zero-drive/freewheel behavior, reciprocity and stress/virtual-work agreement, conservation, load/command causality, time/mesh refinement and failed-step rollback. A supplied-parameter PMDC loop, a prescribed-current FEM animation or postprocessed propeller plot must retain its separate scope until these conditions are met.
