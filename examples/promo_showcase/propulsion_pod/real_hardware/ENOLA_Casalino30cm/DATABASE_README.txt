This dataset contains experimental measurements and numerical results of different propeller geometrie. The dataset is developed in the context of project ENOLA. 

There is a "GeneralInfo" Excel file listing the propellers for which data is available, along with the specific data (experimental measurements, numerical results, simulations, etc.) provided for each one.

The propellers are grouped in "Families" of related propellers. Inside each propeller folder a README explaining the existing data can be found. Data is divided in two categories:
	- results: here experimental measurements and results from numerical simulations are provided. The possible results may include forces, moments and acoustic emissions at different conditions.
	- geometry: here geometry data of the propeller is provided when available. This may include CAD geometry, twist and chord distribution, airfoils used, etc.
